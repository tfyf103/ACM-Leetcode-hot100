# ACM · LeetCode Hot 100

一个只需 **Python 3** 的本地刷题工作台。采用熟悉的 LeetCode 分栏布局，将新版热题 100 改为 **ACM 标准输入 / 标准输出模式**：自己读输入、写 `solve()`、打印答案。

**无需 pip、Node.js、Docker、账号或 API key。题库、代码编辑器和判题均可离线使用。**

## 开始使用

安装 Python **3.9 或更高版本**（已有 Miniconda / Anaconda 也可以直接使用），下载并解压本仓库，在项目目录运行：

```bash
python app.py
```

浏览器会自动打开 <http://127.0.0.1:8765>。终端保持运行，结束时按 `Ctrl+C`。

- **Windows**：直接双击 `start.bat`。支持 Python、Miniconda、Anaconda；无需提前激活环境或安装依赖。
- **macOS / Linux**：执行 `python3 app.py` 或 `sh start.sh`。
- 端口被占用：`python app.py --port 8766`。
- 不自动打开浏览器：`python app.py --no-browser`。

### Windows / Miniconda 启动

已安装 Miniconda 就不需要再安装一份 Python。`start.bat` 会调用 Windows 自带的 PowerShell，逐一验证 Python 版本和 SQLite 模块，自动跳过不可用的 `py` 启动器与 Microsoft Store 别名；也支持项目 .venv、已激活的环境、Python 注册信息、Conda 环境记录和各盘根目录的常见安装位置（例如 `E:\Miniconda3`）。不会下载文件、运行 `pip` 或修改系统 PATH。

```bat
start.bat --check
start.bat --port 8766
start.bat --no-browser
```

`--check` 只显示检测到的 Python 路径和版本；其他参数原样传递给应用。正常启动后请保持终端窗口打开。

如果安装位置特殊或需要指定环境，在项目根目录新建 `python-path.txt`，只写一行完整路径，例如：

```text
E:\Miniconda3\python.exe
```

也可以设置环境变量 `ACM_PYTHON`（优先于该文件），或在已激活环境的 Miniconda Prompt 中启动。`python-path.txt` 不会上传 GitHub。显式指定的路径无效时会报错，避免悄悄使用其他环境。

如果仍使用旧版项目，可临时运行：

```bat
"E:\Miniconda3\python.exe" app.py
```

更新项目时保留 `.local/` 和自己的 `python-path.txt`，以免丢失刷题进度或本机设置。`start.bat` 与 `start.ps1` 需要一起更新。

也可以使用 Git：

```bash
git clone https://github.com/tfyf103/ACM-Leetcode-hot100.git
cd ACM-Leetcode-hot100
python app.py
```

## 如何刷题

1. 打开「题单」，按分类、难度、完成状态或关键词选题。
2. 阅读该题的**输入格式和输出格式**。这里不使用 `class Solution` 接口，也不直接把 LeetCode 的 JSON 示例粘进 stdin。
3. 在右侧 Python 3 编辑器中写完整程序，点击「运行」检查当前输入。
4. 点击「提交」运行该题全部本地测试。通过后记录完成状态；错误时显示失败用例、预期输出、实际输出或异常。
5. 需要时查看题解、历史提交或记笔记。代码草稿自动保存，刷新和重启后可继续。

常用 Python ACM 模板：

```python
import sys

input = sys.stdin.readline

def solve():
    n = int(input())
    nums = list(map(int, input().split()))
    # 根据当前题目的格式读取其他数据并求解
    print(sum(nums))

if __name__ == '__main__':
    solve()
```

## 功能

- 新版 Hot 100：17 个分类、100 道题，逐题 ACM 说明、样例、测试和 Python 参考解法。
- 100 道原创详细题解，每题 8 节：直观做法、逐步推导、正确性、例子演示、时间计算、空间分析、代码易错点、最优性与方案选择。全部离线可读。
- 100 道引导式教学：从题目特征识别方法，逐步回答“为什么”，展开提示与推导，跟随状态表手算，再用口诀、写法骨架与两道自测复习。支持「逐步思考 / 全文阅读」、浅色与深色排版。
- 本地 CodeMirror 编辑器：Python 高亮、行号、自动缩进、括号匹配、字号设置。
- 每 4 个空格一层的缩进线和当前行高亮，工具栏「缩进线」可开关。
- 离线变量提示：输入英文变量名首字母自动提示代码中已有的变量、函数名，以及 Python 常用内置函数和关键字。`Ctrl+Space` 手动打开，方向键选择，`Tab` / `Enter` 接受，`Esc` 关闭；工具栏「补全」可开关。设置刷新后保留。这是词法提示，不会执行代码，也不进行类型推断。
- 左侧题面，右侧编辑器及测试结果；可拖拽分栏，支持浅色 / 深色。
- 自定义标准输入、错误诊断、超时与输出大小限制。
- 多解题专门判定：例如两数之和、异位词分组、最长回文、平衡二叉搜索树等。
- 搜索、分类和难度筛选、收藏、计时器、笔记、提交历史、进度备份导入导出。
- `Ctrl+Enter` 运行，`Ctrl+Shift+Enter` 提交（macOS 使用 `Cmd`）。

## 题库与判题说明

本项目按[当前官方学习计划](https://leetcode.cn/studyplan/top-100-liked/)整理题目，题面以简明中文重新描述并定义 ACM 协议。链表、二叉树、Trie、LRU 等题目使用题面列出的序列或操作输入，不需要额外插件。

每题包含样例和边界测试；集合类答案在题意允许时忽略顺序，浮点答案使用误差容忍。**Accepted 表示通过本项目的测试，不等同于通过力扣官方隐藏测试。** 本地测试并不能证明算法复杂度、原地修改或深拷贝语义；相关要求在题解中说明。

题库现有 **2019 个固定测试**，较原版新增 **1477 个**。98 道题各有至少 20 个不同输入；括号生成和 N 皇后分别完整覆盖所有合法参数 `n=1..8`、`n=1..9`。补充测试用小规模枚举、状态搜索、集合关系等独立方法计算预期答案，未由参考程序生成；启动和判题只读取已保存的固定数据。每题都补充了术语、规则与边界，并提供 **3 个带解释的样例**。

「运行」只执行你当前的 stdin，不增加已完成数量；「提交」才检查整套测试。运行时使用启动应用的同一 Python 解释器。

## 如何阅读详细题解

先在「跟着问题，把解法想出来」中自己回答，再按需展开提示或解答；用手算状态表核对每次状态变化。记住口诀所表达的操作原因，按记忆骨架复写，再用两道自测检查边界和反例。记忆骨架省略输入输出与部分辅助函数，用于还原思路，完整可运行程序位于下方。点击「阅读全文」可展开全部教学解答，提示与深入证明仍可独立展开；阅读方式只影响当前题解。

每题说明状态为何足够、指针为何能移动、更新次序为何安全；先从直观做法推导，再说明高效主解。复杂度逐项说明循环、状态、哈希、输出量及 Python 大整数成本；算法辅助空间、输入存储和结果存储分开计算。回溯题枚举全部结果，不能省略输出量；二分题的对数查询时间也不能替代 ACM 读入数组的线性时间。对高级算法同时解释好记的基础入口与最优性条件，例如爬楼梯的最后一步递推、回文的中心扩展、选择算法的三路分区；不靠难懂公式假装容易记忆。

本次升级 14 道题的参考程序：#5 Manacher、#215 最坏线性选择、#347 频率桶、#279 平方数定理、#148 自底向上链表归并、#32 双向计数、#62 组合数、#416 位集、#22 路径回溯、#51 位掩码、#394 延迟展开、#138 交织复制、#70 快速倍增、#139 Trie 配合动态规划。讲解先介绍容易理解的基础方案，再说明高效主解的必要条件与取舍；不把一种方法称为所有计算模型下唯一的最优解。

自定义输入最多 4 MiB；一般题目输出最多 4 MiB、单个用例限时 5 秒。三数之和可能输出大量合法组合，单独允许 32 MiB 输出和 10 秒；每次提交总限时仍为 35 秒。网页结果区每段最多展示 65,536 个字符并提示截断，判题使用完整输出。

## 保存与迁移

进度、草稿、笔记和提交记录保存在项目的 `.local/` 目录中，已排除 Git 跟踪。请勿删除该目录，除非确实想清空练习记录。可以在网页中导出 JSON 备份，并在另一台电脑导入。此前输入输出专题的历史记录仅作为归档保留在本地数据和备份中，不再出现在题库里；旧备份仍可导入。

也可以指定数据目录：

```bash
python app.py --data-dir path/to/my-progress
```

## 本机运行范围

服务仅监听 `127.0.0.1`，适合个人电脑使用。提交的 Python 代码以当前用户身份执行，可以访问本机文件；超时和输出限制不是操作系统沙箱。仅运行你信任的代码，不应把端口代理到公网或用作多人在线评测服务。

## 开发与测试

```bash
python -m unittest discover -s tests -v
python tools/verify_catalog.py
```

可选前端行为回归：`node tests/test_frontend.cjs` 和 `node --test tests/test_frontend.js tests/test_editor.cjs`。Node.js 只用于开发测试，日常刷题仍只需 Python。

`catalog/enrichment.json` 保存补充题面与固定用例；`catalog/enrichment.py` 将它们合并到原题库。开发工具 `python tools/build_practice_cases.py` 根据固定种子与独立预期计算器重新生成该数据，中文说明维护在 `tools/practice_details.json`。应用启动不会运行生成工具。题库验证工具会检查实际合并后的全部题目。

`catalog/tutorials.json` 保存 100 道题的 800 节讲解，原文维护在 `tools/build_tutorials.py`；`catalog/optimal_solutions.json` 保存 14 个升级程序，维护在 `tools/build_optimal_solutions.py`。修改后分别运行对应工具，再运行全部验证。应用只读取固定 JSON，无联网或动态生成步骤。独立回归还检查回文与括号穷举、选择算法的逆序及重复值、平方数 DP 对照、深层解码，以及随机链表复制的对象隔离和原链恢复。

引导式教学维护在 `tools/guide_notes/*.json`，运行 `python tools/build_guides.py` 检查覆盖、提问、表格、复习与自测结构，并合成 `catalog/guides.json`。运行时将其放入 `tutorial.guide`；旧版八节说明保留在折叠的深入理解区。文字均为固定原创内容，记忆骨架仅作为纯文本展示，生成工具与应用不会执行它们。

结构：`app.py`（HTTP / 持久化）、`judge.py`（运行及判题）、`catalog/`（题库）、`static/`（离线网页）。不需要前端构建步骤。
